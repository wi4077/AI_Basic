# 🎓 지도학습 알고리즘 클래스 스튜디오

기계학습 알고리즘의 원리를 시각적으로 이해하고 매개변수의 영향을 직접 실험해보는 인터랙티브 학습 플랫폼입니다.

## 📚 학습 내용

### 1️⃣ 선형 회귀 & 이상치 (Regression)
- **목표**: 이상치(Outlier)가 회귀선에 미치는 영향 이해
- **기능**:
  - 빨간색 이상치점을 드래그하여 회귀선의 변화 관찰
  - 이상치 가중치 조절로 기울기 변형 정도 측정
  - 최소제곱법(Least Squares) 원리 학습

### 2️⃣ K-NN 분류 (K-Nearest Neighbors)
- **목표**: K값에 따른 결정 경계의 부드러움 비교
- **기능**:
  - K값 변경으로 다중 그룹 분류 결과 변화 관찰
  - 결정 경계(Decision Boundary) 시각화
  - 다수결 원리 및 유클리드 거리 학습

### 3️⃣ 결정 트리 (Decision Tree)
- **목표**: 트리 깊이에 따른 영역 분할 패턴 이해
- **기능**:
  - 깊이(Depth) 조절로 분할 선 개수 변화 관찰
  - 지니 불순도(Gini Impurity) 최소화 원리 학습
  - 과소적합 vs 과대적합 개념 인식

### 4️⃣ 서포트 벡터 머신 (SVM)
- **목표**: 마진 최대화와 서포트 벡터의 역할 이해
- **기능**:
  - 마진 폭 조절로 서포트 벡터 변화 관찰
  - 최적 경계선 찾기 실험
  - 클래스 침범 오류 감지

## 🛠️ 프로젝트 구조

```
AI_Basic/
├── index.html          # 메인 HTML 구조
├── style.css           # 스타일 시트
├── script.js           # JavaScript 로직
└── README.md           # 프로젝트 설명
```

### 파일 역할
- **index.html**: 페이지 레이아웃 및 UI 요소 정의
- **style.css**: 전체 시각적 스타일링 (Tailwind-like 디자인)
- **script.js**: 4개 알고리즘 시뮬레이터의 핵심 로직

## 🚀 사용 방법

1. 브라우저에서 `index.html` 파일 열기
2. 홈 화면에서 학습하고 싶은 알고리즘 카드 선택
3. 슬라이더와 컨트롤을 조작하여 실시간 시뮬레이션 관찰
4. 💡 "수학 원리" 버튼으로 각 알고리즘의 수식 확인

## 🎯 학습 미션

각 시뮬레이터마다 **탐구 미션**이 제시됩니다:

- **회귀**: 이상치 기울기 변형률 100% 이상 만들기
- **K-NN**: K=1과 K=15의 결정 경계 차이 비교하기
- **결정 트리**: Depth 변화에 따른 과적합 위험 인식
- **SVM**: 마진 최대화 조건에서 최적 경계선 찾기

## 🎨 기술 스택

- **HTML5**: 의미있는 마크업 구조
- **CSS3**: Grid, Flexbox, 그라데이션 효과
- **Canvas API**: 실시간 그래픽 렌더링
- **Vanilla JavaScript**: 순수 JS로 구현된 인터랙티브 시뮬레이션
