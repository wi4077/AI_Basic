# 알고리즘 카드 스튜디오

지도학습 알고리즘의 개념을 카드뉴스로 읽고, 각 알고리즘의 핵심 변수를 캔버스에서 직접 조작하는 교육용 웹 앱입니다.

## 구현 알고리즘

### 1. 선형 회귀
- 데이터 개수와 잡음 조절
- 데이터 점 드래그
- 최소제곱 회귀선, 회귀식, 평균제곱오차 표시
- 축 눈금과 잔차선 표시
- 기울기·절편 계산 과정과 X값 예측

### 2. 로지스틱 회귀
- 기울기와 절편 조절
- 분류 기준 확률 조절
- 결정 경계와 분류 정확도 표시
- 데이터 점 드래그
- 시그모이드 곡선과 평균 예측 확률 표시

### 3. K-최근접 이웃
- K값 조절
- 그룹 수와 그룹별 데이터 수 조절
- 대상 점 드래그
- 최근접 이웃 연결선과 다수결 결과 표시
- 최근접 이웃 거리와 순위 표시

### 4. K-평균
- 클러스터 수와 데이터 수 조절
- 초기 중심과 데이터 그룹 표시
- 한 단계 학습 버튼으로 점 할당 및 중심 이동
- 반복 단계와 상태 표시
- 중심 이동 전후 선과 클러스터별 WCSS 표시

### 5. 의사결정트리
- 트리 깊이 조절
- 지니 불순도 기반 분할선 표시
- 분할선 수와 평균 지니 불순도 표시
- 데이터 점 드래그 및 샘플 재생성
- 실제 분할 질문을 입력 좌표 기준으로 표시

### 6. 서포트 벡터 머신
- 마진 폭과 결정 경계 기울기 조절
- 데이터 점 드래그
- 서포트 벡터 수와 클래스 침범 오류 표시
- 마진 안쪽 점과 오분류 점을 구분해 강조

## 사용 방법

1. `index.html`을 브라우저에서 엽니다.
2. 홈 화면에서 알고리즘 카드를 선택합니다.
3. 개념 카드에서 핵심 개념과 조작 항목을 읽습니다.
4. `시뮬레이터로 이동` 버튼을 눌러 실험합니다.

## 기술 스택

- HTML5
- CSS3
- Canvas API
- Vanilla JavaScript

모든 시뮬레이터는 마우스와 터치 드래그를 지원합니다.

## 직접 데이터 입력

각 시뮬레이터의 조절판에 있는 표에 행별로 입력할 수 있습니다. 선형 회귀 좌표는 0~10 범위로 입력해 작은 값의 차이를 크게 관찰할 수 있으며, 나머지 알고리즘의 좌표는 0~100 범위입니다. 그룹이나 클래스가 필요한 알고리즘은 세 번째 열도 입력합니다.

| 알고리즘 | 입력 열 |
| --- | --- |
| 선형 회귀, K-평균 | X, Y |
| 로지스틱 회귀, KNN, 의사결정트리, SVM | X, Y, 그룹/클래스 |
 
`행 추가`로 입력 행을 늘릴 수 있습니다.

`입력 적용`으로 데이터를 반영하거나 `랜덤 데이터` 버튼으로 새 샘플을 만들 수 있습니다.

랜덤 데이터는 알고리즘마다 여러 패턴을 무작위로 선택합니다. 선형 회귀는 상승·하락·곡선·완만한 패턴, 분류 알고리즘은 군집 위치·경계·겹침 정도가 달라진 데이터를 생성합니다.
